# 수동 테스트 매트릭스

릴리스 전에 실제 Windows 에서 확인하는 목록입니다. 자동 테스트(`dotnet test`)는 순수 로직만 검증하고,
caret 탐색·IME 판정·창 z-order 는 실제 앱에서만 확인할 수 있습니다.

표기: ✅ 정상 · ⚠️ 알려진 한계 · ❌ 버그 · ⬜ 미확인

## 2. 설정·트레이

| 항목 | 확인 내용 | 결과 |
|---|---|---|
| 모양 5종 | 각각 즉시 반영, 재시작 후 유지 | ⬜ |
| 위치 위/아래/왼쪽 | 위쪽 공간이 없으면 아래로, 왼쪽 공간이 없으면 오른쪽으로 | ⬜ |
| 그림자 | 파란 선택 영역 위의 파란 배지도 윤곽이 보임 | ⬜ |
| 애니메이션 | 배지가 처음 뜰 때 페이드인, 한/영 전환 시 살짝 커졌다 돌아옴. 설정 또는 Windows "애니메이션 효과"를 끄면 즉시 표시 | ⬜ |
| 크기 80~160%, 설정 창 50~300% | | ⬜ |
| 불투명도 | 50% 에서 배지 배경 뒤 글자가 비치고 배지 글자는 또렷함 | ⬜ |
| 색상 변경 | 미리보기와 실제 배지가 같음. 노란색을 고르면 글자가 검은색으로 바뀜 | ⬜ |
| 트레이 프리셋 | 설정 창에서 90% 로 두면 크기 메뉴에 "사용자 지정 (90%)" 가 체크되어 보임 | ⬜ |
| 일시 중지 | 메뉴·Ctrl+Alt+H·트레이 아이콘 회색 + 일시 정지 표시, 툴팁 "일시 중지" | ⬜ |
| 트레이 상태 아이콘 | 메모장에서 한/영 전환 시 트레이 아이콘이 한/A 로 바뀜. 바탕화면 클릭 시 커서 아이콘으로 복귀. 설정에서 끄면 항상 커서 아이콘 | ⬜ |
| Caps Lock | 영문 모드에서 Caps Lock 을 켜면 배지가 `ABC`, 트레이가 `A` + 밑줄, 툴팁·메뉴 상태 줄에 "(Caps Lock)". 한글 모드에서는 변화 없음. 설정에서 끄면 항상 `A` | ⬜ |
| 트레이 클릭 | 왼쪽 클릭 → 설정 창. 메뉴 맨 위에 "현재: …" 상태 줄 | ⬜ |
| 트레이 아이콘 DPI | 150% 모니터에서 아이콘이 흐리지 않음(24px 로 다시 그림) | ⬜ |
| 실시간 반영 | 설정 창에서 슬라이더를 끌면 창 밖 배지가 바로 바뀜. 취소 → 원래대로. 확인 → 유지·저장 | ⬜ |
| 설정 창 반응성 | 설정 창이 활성일 때 배지가 숨겨지고 깜빡이지 않음. 버튼·슬라이더가 즉시 반응. 메모장으로 전환하면 배지가 새 설정으로 보임 | ⬜ |
| 다크 모드 | Windows 앱 모드 어둡게: 설정·정보 창 배경·제목 표시줄·트레이 메뉴가 어둡고 글자가 읽힘 | ⬜ |
| 밝게/어둡게 전환 | 앱 실행 중 전환하면 트레이 메뉴 색이 따라옴(설정 창은 다시 열면 반영) | ⬜ |
| 고대비 모드 | 색을 입히지 않고 시스템 색 그대로. 카드 테두리가 보임 | ⬜ |
| 자동 시작 | 메뉴 체크 → 재로그인 시 실행. 설치 프로그램 옵션과 동일 값 | ⬜ |
| 업데이트 확인 | 수동: 최신/새 버전/오프라인 3가지 대화상자(TaskDialog). 새 버전이면 열기/나중에/건너뛰기 | ⬜ |
| 건너뛴 버전 | "이 버전 건너뛰기" 뒤 자동 확인에서 풍선이 안 뜸. 수동 확인에서는 다시 보임 | ⬜ |
| 정보 | 큰 아이콘·버전 표시, 링크(새 버전 확인·저장소·릴리스·설정 폴더·로그 폴더), 진단 정보 복사 → 붙여넣기 확인 | ⬜ |
| 단축키 변경 | 입력칸 클릭 후 Ctrl+Shift+F9 → 표시·즉시 동작·재시작 후 유지. Shift+H 만 누르면 경고음. 겹치는 조합이면 확인 시 경고 | ⬜ |
| 제외 앱 목록 | 실행 중 앱 목록에서 고르기, 직접 입력 + Enter, Delete 키로 삭제, 중복 추가 안 됨 | ⬜ |
| 니모닉·툴팁 | Alt+M 으로 배지 모양으로 이동, 항목에 마우스를 올리면 툴팁 | ⬜ |
| 작은 아이콘 | 100% 트레이(16px)에서 커서·배지 도형이 뭉개지지 않음 | ⬜ |
| 중복 실행 | 두 번째 실행 → 기존 설정 창이 열림 | ⬜ |
| 첫 실행 | 풍선 알림 1회 | ⬜ |
| 설정 이관 | 0.x 의 exe 옆 파일 → %APPDATA% 로 복사 | ⬜ |

## 3. 환경

| 항목 | 확인 내용 | 결과 |
|---|---|---|
| DPI 100% / 150% / 200% | 배지 크기·위치 | ⬜ |

| 트리밍 빌드 | ColorDialog, HttpClient, Registry 동작 | ⬜ |
| 유휴 CPU | 작업 관리자에서 1% 미만 | ⬜ |
| 장시간(8시간) 실행 | 메모리 증가 없음 | ⬜ |
