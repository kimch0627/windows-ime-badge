# 수동 테스트 매트릭스

릴리스 전에 실제 Windows 에서 확인하는 목록입니다. 자동 테스트(`dotnet test`)는 순수 로직만 검증하고,
caret 탐색·IME 판정·창 z-order 는 실제 앱에서만 확인할 수 있습니다.

표기: ✅ 정상 · ⚠️ 알려진 한계 · ❌ 버그 · ⬜ 미확인

## 1. 앱별 배지 표시

| 앱 | 입력 위치 | caret 경로 | 한↔영 전환 | 위치 | 비고 |
|---|---|---|---|---|---|
| 메모장 (Win11) | 본문 | Win32 | ⬜ | ⬜ | |
| Word | 본문 | Win32 | ⬜ | ⬜ | |
| Excel | 셀 편집 | Win32 | ⬜ | ⬜ | 셀 선택 상태에서는 caret 없음 |
| Chrome | 주소창 | UIA text | ⬜ | ⬜ | "문서 처음~커서" 범위 접기 |

## 2. 설정·트레이

| 항목 | 확인 내용 | 결과 |
|---|---|---|
| 모양 5종 | 각각 즉시 반영, 재시작 후 유지 | ⬜ |
| 위치 위/아래 | 위쪽 공간이 없으면 아래로 | ⬜ |
| 크기 80~160%, 설정 창 50~300% | | ⬜ |
| 불투명도 | 50% 에서 배지 배경 뒤 글자가 비치고 배지 글자는 또렷함 | ⬜ |
| 색상 변경 | 미리보기와 실제 배지가 같음. 노란색을 고르면 글자가 검은색으로 바뀜 | ⬜ |
| 트레이 프리셋 | 설정 창에서 90% 로 두면 크기 메뉴에 "사용자 지정 (90%)" 가 체크되어 보임 | ⬜ |
| 일시 중지 | 메뉴·Ctrl+Alt+H·트레이 아이콘 회색 | ⬜ |
| 자동 시작 | 메뉴 체크 → 재로그인 시 실행. 설치 프로그램 옵션과 동일 값 | ⬜ |
| 업데이트 확인 | 수동: 최신/새 버전/오프라인 3가지 대화상자(TaskDialog). 새 버전이면 열기/나중에/건너뛰기 | ⬜ |
| 건너뛴 버전 | "이 버전 건너뛰기" 뒤 자동 확인에서 풍선이 안 뜸. 수동 확인에서는 다시 보임 | ⬜ |
| 정보 | 버전 표시, 폴더 열기 링크 4개 | ⬜ |
| 중복 실행 | 두 번째 실행 → 기존 설정 창이 열림 | ⬜ |
| 첫 실행 | 풍선 알림 1회 | ⬜ |
| 설정 이관 | 0.x 의 exe 옆 파일 → %APPDATA% 로 복사 | ⬜ |

## 3. 환경

| 항목 | 확인 내용 | 결과 |
|---|---|---|
| DPI 100% / 150% / 200% | 배지 크기·위치 | ⬜ |
| 모니터 2대, 배율 다름 | 모니터 넘어갈 때 배율 변경 | ⬜ |
| 모니터 연결/해제 중 | 예외 없이 계속 동작(DisplaySettingsChanged) | ⬜ |
| 화면 잠금 → 해제 | 폴링 멈춤 → 재개 | ⬜ |
| 절전 → 복귀 | 배지 정상 | ⬜ |
| Program Files 설치 | 설정 저장이 됨(%APPDATA%) | ⬜ |
| 트리밍 빌드 | ColorDialog, HttpClient, Registry 동작 | ⬜ |
| 유휴 CPU | 작업 관리자에서 1% 미만 | ⬜ |
| 장시간(8시간) 실행 | 메모리 증가 없음 | ⬜ |
